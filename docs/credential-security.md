# Credential Security

**Status:** Planned — implemented in Phase 10 (Credentials). See
[ROADMAP.md](../ROADMAP.md).

This document will describe: encrypted-at-rest credential storage, the
environment-based master-key configuration, organization/workflow scoping,
credential reference resolution (definitions never contain raw secret values),
redaction guarantees across logs/snapshots/API responses/error
messages/audit events, key rotation, revocation, and credential-access auditing.

See also [SECURITY.md](../SECURITY.md) for the overall security principles this
document elaborates on.
